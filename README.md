# Audio Bridge

### 把你的电脑变成蓝牙音箱

Windows 10 之后系统其实已经支持"让电脑接收手机传来的蓝牙音频"，但微软没有给一个能用的管理界面——你得自己写代码调 API 才能用起来。Audio Bridge 就是来补上这个缺口的：装上它，你的电脑就能像蓝牙音箱一样，接收手机、平板推送的音乐、播客、导航语音，声音直接从电脑喇叭/耳机里出来。

> 适合：想用电脑音响听手机音乐的人、开发调试蓝牙音频的人、想把手机当音频源投到会议室电脑的人。

---

### 它能做什么

| 场景 | 说明 |
|---|---|
| **接收蓝牙音频** | 手机连上电脑后，手机里播放的声音会从电脑的扬声器/耳机里放出来 |
| **一键切设备** | 点托盘图标 → 弹出设备列表 → 选哪台连哪台，不用进系统设置 |
| **断了自动重连** | 蓝牙断连后自动按智能节奏重试，不用手动盯着 |
| **开机自动启动** | 可选开机自启，开机后自动恢复上次连接 |
| **记住多台设备** | 配过的设备都记着，下次直接选，不用重新配对 |
| **托盘里安安静静** | 不占任务栏、不弹窗，只在右下角放一个小图标 |

---

### 核心亮点

- **新旧蓝牙都支持**：同时兼容经典 A2DP（绝大多数蓝牙设备）和 LE Audio 低功耗音频（蓝牙 5.2+ 新设备），系统自动协商最佳协议，设备列表里会标 `[A2DP]` / `[LE Audio]` 让你一目了然
- **音质不掉链子**：连接期间自动给进程提升到"专业音频"优先级，锁住系统执行状态，减少卡顿爆音
- **一个安装包通吃三套架构**：x86 / x64 / ARM64 全打包，安装时自动选对的版本装上（Surface Pro X 这种 ARM 本也能用）
- **跟系统语言走**：中文（简/繁）、英文自动切换，界面跟系统设置一致
- **断连有通知**：连上、断开都会冒一个系统通知告诉你

---

### 怎么用（三步）

1. **装好，配对设备** — 在 Windows 蓝牙设置里把手机/平板像连蓝牙耳机一样配对上（托盘右键 → "蓝牙设置"直接进）
2. **点托盘图标，选设备** — 弹出设备列表，点你要连的那个
3. **手机里放音乐** — 声音从电脑出来了，享受吧

---

### 系统要求

- Windows 11 22H2 或更高版本
- 一台支持蓝牙的电脑（自带或买个蓝牙适配器都行）
- 装完会在桌面和开始菜单生成快捷方式，可选是否开机自启
